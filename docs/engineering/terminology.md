# Canonical terminology

| Designation | Engineering function |
|---|---|
| Prefabulated amulite | Structural foundation and support datum |
| Malleable logarithmic casing | Segmented enclosure and guarded access |
| Ambifacient lunar waneshaft | Coaxial shaft transmitting rotor torque |
| Hydrocoptic marzelvane | Indexed rotor air-moving element |
| Spurving bearing | Radial support cartridge and journal interface |
| Panametric fan | Independently powered cooling airflow stage |
| Lotus-o-deltoid winding | Grouped motor conductor path and terminals |
| Panendermic semi-boloid slots | Mathematically indexed stator slots |
| Differential girdle spring | Stationary or torsional compliance according to the machine definition |
| Cardinal gram-meter | Synchronized sensor acquisition and conditioning |
| Unilateral phase detractor | Complex phase estimation at a specified frequency |
| Non-reversible tremie pipe | One-direction fluid path and service fittings |
| Drawn reciprocating dingle arm | Crank-slider link and output interface |

ME-01 scientific subsystem definitions, equations and links are published in the [subsystem register](https://rrg314.github.io/turbo-encabulator/#/me01/systems).
