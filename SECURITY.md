# Security and publication

The site is a public static distribution. CAD, data, browser bundles, issues, and build logs are publicly readable. Keep credentials, private asset archives, personal data, local configuration, and unpublished third-party material outside contributions.

Report application security issues through [private vulnerability reporting](https://github.com/RRG314/encabulator-lab/security/advisories/new). Include a minimal reproduction with synthetic data and the affected commit. Submit non-sensitive geometry or numerical issues through the public issue forms.

The browser simulation runs locally and has no path to drive physical equipment. Model selection, current selection, and saved camera positions are browser-local. The site uses no tracking, third-party runtime asset hosts, or registered account login.
