# Changelog

## Unreleased

- Expanded the ME-01 specification, governing equations, input tables and verification protocol.

## 0.1.0 · 2026-11-17

First public release.

### Turbo and Retro engineering program

- Established the canonical 30-part registry and nine assembly records.
- Added reversible explosion, engineering lookup, cutaway, visibility, isolation, component measurement and camera bookmarks.
- Implemented preliminary FreeCAD/OpenCascade geometry, neutral exports and 22 drawing review sheets.
- Added ten deterministic studies, diagnostic fault replay and published digital verification results.
- Configured GitHub Pages deployment.

- Added the independently parametrized Retro Encabulator RE-01, its registry, reference solids and operating studies.
- Preserved the Turbo Encabulator TE-01 and enhanced its CAD, service metadata and operating console.
- Added machine comparison, source traceability, light workbench finishes and contribution tooling.

### Metachronic engineering program and archive

- Established the Metachronic Encabulator ME-01 Polychronous Differential Synchronization Configuration as the third equipment family.
- Added the dual-shaft CAD assembly, 21 scientific subsystem studies, six host boundaries, and a coupled regenerative operating laboratory.
- Published engineering plates, source traceability, stable part identifiers and three-machine verification coverage.
- Expanded the archive to 25 configurations and 35 sources, with eight explodable assemblies and original source comparisons where available.
- Added animated operating fixtures, adjustable loads, X-ray inspection, and configuration submissions.
- Renamed the repository to Encabulator Lab and introduced the Encabulation Systems Inc portal with an interactive, explodable ME-01 preview.
- Added software citation and Zenodo archival metadata for the first public release.
