# RE-01 technical drawings

Run `scripts/freecad-re01.sh` with a FreeCAD-enabled interpreter. The generator writes standalone part and assembly SVGs to `public/models/re01/drawings/` along with a downloadable archive. Scope includes all 49 current part records, all 15 assembly groups, and full assembled and separated views. Dimensions are schematic reference dimensions. Machining tolerances, surface finish and material certifications remain open.
