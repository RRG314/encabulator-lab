# Turbo Encabulator TE-01 model

The established TE-01 solid builders remain at `cad/components/`, with canonical placement rules in `cad/assemblies/`, parameters in `cad/parameters.py` and the assembly entry point in `cad/te01_master_assembly.py`. Run `scripts/freecad.sh --mode all` from the repository root. The retained paths preserve existing consumers and the earlier rig configuration.
