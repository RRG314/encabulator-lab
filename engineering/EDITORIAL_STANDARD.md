# Technical publication standard

Use the full machine designation at first mention. Follow the registry for part IDs, component names, quantity and configuration ownership. Describe a component through its mechanical, electrical, fluid or computational function. Give equations with variables and units, with an applicable model boundary.

Identify design nominal dimensions, calculated geometry, simulated results and measured evidence. Make unresolved selections and qualification gates specific. Link primary references and distinguish established principles from project design choices.

Every published change names the affected identifiers, the tested revision, and the basis for the result. Keep private configuration and working notes outside the deployable site. Use technical language in interface text, documentation and release notes.
